# 📊 Microsoft Excel Practice Labs

A collection of practical Microsoft Excel lab exercises covering **spreadsheet fundamentals, formulas, cell references, data management, tables, sorting, filtering, data validation, error handling, and lookup functions**.

These labs are designed to build practical Excel skills for **data organization, data analysis, validation, and error management**.

The first lab focuses on understanding the basic features of Microsoft Excel and working with formulas and cell references.

### Topics Covered

- Creating and managing worksheets
- Renaming and organizing sheets
- Cell and data formatting
- Relative cell references
- Absolute cell references
- Mixed cell references
- Basic Excel formulas
- `SUM()` and `PRODUCT()` functions
- Creating tables and formatted datasets
- Applying formulas across multiple cells
- Using absolute references for calculations

## 🧪 Lab 1.3 — Error Handling & Lookup Functions

The third lab focuses on identifying, classifying, and handling common Excel errors and managing errors produced by lookup functions.

### ⚠️ Error Identification

- Using `ISERROR()` to identify errors
- Understanding common Excel error types
- Detecting errors within datasets

### 🔎 Error Classification

- Using `ERROR.TYPE()` to classify Excel errors
- Identifying different types of Excel errors
- Understanding error codes and their meanings

### 🔧 Error Correction

- Identifying incorrect cell references
- Fixing `#VALUE!` errors
- Understanding the causes of common formula errors
- Verifying corrected formulas

### 🔍 Lookup Error Handling

- Using `VLOOKUP()` for data retrieval
- Handling `#N/A` errors
- Using `IFNA()` to provide alternative results when lookup values are not found
- Improving the readability of lookup results
